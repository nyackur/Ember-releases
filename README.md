# Ember — релизы

Готовые сборки **Ember** — загрузчика видео и аудио из TikTok. Исходный код в этом репозитории не хранится.

Скачайте файл для своей системы на странице [Releases](../../releases/latest):

| Система | Файл |
|---|---|
| Android 10+ (arm64) | `ember-<версия>-android-arm64.apk` |
| Windows (x86_64) | `ember-<версия>-windows-x86_64.zip` или `.exe` |
| Linux (x86_64) | `ember-<версия>-linux-x86_64.tar.gz` (с установщиком и иконками) |

Рядом с каждым файлом лежит `.sha256` для проверки целостности. Само приложение при запуске проверяет этот репозиторий и сообщает о новой версии.
